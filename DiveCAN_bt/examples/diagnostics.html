Calibration

Manual Setpoint

Firmware clamps to 0.40–1.60 bar; effective only in a setpoint-controlled PPO2 mode.

Solenoid Override (HIL)

Raw-fires the solenoid for a fixed ~1.5 s. The firmware requires a programming session at the surface with PPO2 mode OFF; this enters the programming session for you before firing.

PID Autotune

Preconditions

The autotune routine applies one bounded, known duty excitation, records commanded solenoid duty against PPO2, identifies the delayed mixing plant, then derives gains from that model. It demands a controlled environment:

  • Surface only — the run auto-aborts if a dive is detected.
  • PPO2 mode must be PID — otherwise START is refused (NRC 0x22).
  • Cells calibrated & healthy — a cell failure aborts the run.

START requires a programming session; enter it here before starting.
