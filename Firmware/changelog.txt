## 0.0.2 - 2026-10-20

### Added
- Automatically start handset when board boots up
- Log ambient/tank pressure and power (battery voltage and current) to the onboard flash log
- Preliminary support for the DiveCAN MainPCB board with SD-card storage (not yet hardware-qualified; this release qualifies the Jr variants)

### Changed
- Inhibit O2 flushing onto cells when depth is below 10m
- Change HP sensors to not broadcast on errors, rather than broadcast an error sentinel
- Lower the default PID proportional gain (Kp 1.0 to 0.4) based on loop-dynamics observations
- Poseidon_Aren: the O2 tank pressure transducer now scales to 200 bar full scale (was 300 bar), correcting low-pressure clipping

### Fixed
- Added inhibit to prevent spurious power on if the BUS EN line remains low after boot checks are complete
- Fix an issue where the board could crash when downloading large amounts of log data due to an error histogram write occuring at the same time
- Fix the head going silent (no PPO2 broadcasts, no handset replies) for several seconds when a setting is saved shortly after boot
- Record a failed battery current read in the persistent error counters instead of only a log message
- Fix dive start and dive end markers being swapped in the flash log
- Fix the O2 flush solenoid staying on through the diluent flush during the Check calibration mode (each flush burst is now switched off explicitly instead of relying on the shared solenoid deadman timer)
- Fix force-revert, factory flash erase, NVS erase and log erase being refused while a downloaded OTA image is waiting to be activated

## 0.0.1 - 2026-07-29

### Added

- Initial numbered firmware release workflow with serialized HIL qualification
  for every production variant.
- Complete and per-variant downloadable release packages containing the exact
  tested full-flash and signed OTA images, qualification records, and SHA-256
  checksums.
